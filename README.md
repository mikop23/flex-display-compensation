# Flex Display Compensation

휘고 늘어나는 디스플레이의 기하 왜곡과 휘도 불균일을 보정하는 **시뮬레이터**를 직접 만들고,
그 안에서 하드웨어 해법(기판 구조, 소자, 광학)을 파라미터로 실험해서
"소프트웨어가 어디까지 보정하고, 하드웨어가 무엇을 받쳐줘야 하는지"를 수치로 분석한다.

## 진행 현황

| 단계 | 메인 트랙 (SW) | 서브 트랙 (HW 연구) | 상태 |
|---|---|---|---|
| 0 | 기초 도구 (Python, NumPy, 영상처리) | - | 완료 |
| 1 | 기하 왜곡 보정 | 오그제틱·키리가미 기판 | 진행 중 |
| 2 | 휘도 불균일 보정 (디무라) | 픽셀 보상 회로 | 대기 |
| 3 | 변형 물리 모델링 | 중립면·구조 최적화 | 대기 |
| 4 | 실시간 적응형 통합 보정 | 광학 보조, SW-HW 분담 비교 | 대기 |

## 증명 기준 (계속 다듬음)

- 기하 왜곡: 보정 후 픽셀 위치 오차 < 1 px
- 휘도 균일도: 보정 후 휘도 편차 ΔL < 2 %
- 적용 범위: 위 기준을 지키는 곡률 반경 / 신장률(%)
- 실시간성: 보정 지연 시간

## 폴더 구조

- `log/` 세션 로그 (날짜별)
- `stages/N-*/` 단계별 노트, 코드, 결과, 보고서, 하드웨어 연구
- `LIMITS.md` 소프트웨어 보정의 한계 → 하드웨어 후보
- `QUESTIONS.md` 나중에 볼 궁금한 것
